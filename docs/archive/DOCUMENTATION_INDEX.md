## 🚀 Quick Start

Don't want to read? Just do this:

```bash
# Install
composer install
npm install

# Setup
cp .env.example .env
php artisan key:generate
touch database/database.sqlite
php artisan migrate

# Start
npm run dev
```

Visit: **http://localhost:8000**

For details, see [START_HERE.md](START_HERE.md)
