# Quick Start Guide

Get Himinbjörg running in minutes!

## Prerequisites

- **PHP** 8.2 or higher
- **Node.js** 20 or higher
- **Composer** 2.x
- **Database**: SQLite (default), MySQL, or PostgreSQL

## Method 1: Docker (Recommended)

### Using Docker Compose

```yaml
# docker-compose.yml
version: "3"
services:
  himinbjorg:
    image: your-registry/himinbjorg:latest
    container_name: himinbjorg
    ports:
      - "80:80"
    volumes:
      - ./config:/config
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=America/New_York
    restart: unless-stopped
```

```bash
docker-compose up -d
```

Visit http://localhost

### Using Docker Run

```bash
docker run -d \
  --name=himinbjorg \
  -e PUID=1000 \
  -e PGID=1000 \
  -e TZ=America/New_York \
  -p 80:80 \
  -v ./config:/config \
  --restart unless-stopped \
  your-registry/himinbjorg:latest
```

## Method 2: Traditional Install

### 1. Clone Repository

```bash
git clone https://github.com/your-org/himinbjorg.git
cd himinbjorg
```

### 2. Install Dependencies

```bash
# PHP dependencies
composer install

# JavaScript dependencies
npm install
```

### 3. Configure Environment

```bash
# Copy example environment file
cp .env.example .env

# Generate application key
php artisan key:generate

# Edit .env file
nano .env
```

**Minimum required settings:**
```env
APP_NAME=Himinbjörg
APP_ENV=local
APP_KEY=base64:...  # Generated by artisan key:generate
APP_DEBUG=true
APP_URL=http://localhost

DB_CONNECTION=sqlite
DB_DATABASE=/absolute/path/to/database.sqlite
```

### 4. Set Up Database

```bash
# Create SQLite database
touch database/database.sqlite

# Run migrations
php artisan migrate

# Seed with default data
php artisan db:seed
```

### 5. Build Frontend

```bash
npm run build
```

### 6. Start Server

```bash
# Development
npm run dev
# Runs on http://localhost:8000

# Production
php artisan serve --host=0.0.0.0 --port=80
# Or use Apache/Nginx
```

## First Time Setup

### 1. Access Application

Navigate to http://localhost (or your configured URL)

### 2. Add Your First App

1. Click the **Settings** button (gear icon)
2. Click **Edit** mode
3. Click **Add Item**
4. Fill in:
   - **Title**: My App
   - **URL**: https://myapp.com
   - **Application Type**: (Optional) Select from 491 apps
   - **Color**: Auto-extracted or custom
5. Click **Save**

### 3. Organize with Tags

1. Enable **Edit** mode
2. Create tags/folders
3. Drag apps to organize
4. Pin favorites to dashboard

### 4. Configure Settings

Click **Settings** → Configure:
- **System**: Language, version info
- **Appearance**: Background, trianglify patterns
- **Miscellaneous**: Search provider, link behavior
- **Advanced**: Custom CSS/JS

## Common Issues

### Port Already in Use

**Problem**: Port 80/8000 is already taken

**Solution**:
```bash
# Use different port
php artisan serve --port=8080

# Or with Docker
docker run -p 8080:80 ...
```

### Database Connection Error

**Problem**: Can't connect to database

**Solution**:
```bash
# For SQLite, check file exists
ls -la database/database.sqlite

# Check permissions
chmod 664 database/database.sqlite
chmod 775 database/

# For MySQL/PostgreSQL, verify credentials in .env
```

### Build Fails

**Problem**: `npm run build` fails

**Solution**:
```bash
# Clear cache and rebuild
npm run clean
npm install
npm run build

# Check Node version
node -v  # Must be 20+
```

### White Screen

**Problem**: Page loads but shows nothing

**Solution**:
```bash
# Check browser console for errors
# Rebuild assets
npm run build

# Clear Laravel cache
php artisan cache:clear
php artisan config:clear
php artisan view:clear

# Check logs
tail -f storage/logs/laravel.log
```
